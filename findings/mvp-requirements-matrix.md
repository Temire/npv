## Source of truth and reconciliation

Primary available client evidence is `product-docs/user-feedback.md`, which contains the Feb. 7, 2024 submission/search definition, the Sep. 20, 2024 portal review, later comments and a discovery call transcript summary. The client defines a valid record as a survey plan, one financial record (receipt, contract of sale, deed/assignment, etc.), seller and buyer information, submitter contact information, agent affidavit if submitted by an agent, and a submitter profile (lines 42–48). Search input is a survey plan number or Certificate of Submission number (lines 42–43).

The same feedback requests public survey verification and overlap prompts, with consent/account prompts for adding records (lines 76–82, 575–587); per-user privacy, optional public visibility, generated certificates and search reports, and account/property deletion (lines 89–139); admin-only account creation, protected admin login, document management, field correction and reviewer feedback (lines 178–205, 260–280); and portal/email notifications (lines 130–138, 270–274). Later discussion distinguishes property verification/search reports from non-identifiable data trends and proposes pay-per-use first, with subscriptions later (lines 621–668).

Supporting client PDFs are present: `MVP Features_NPV.pdf`, `User Story Mapping_NPV.pdf`, `Sample Certificate.pdf`, `Sample search report.pdf`, `Survey Plan_merged.pdf`, `NPV_Service Level Agreement.pdf`, `NPV_Service Level Agreement_4.pdf`, `NPR - Summary of Work Breakdown_.pdf`, and coordinate-conversion references. The workspace has no PDF text extraction utility or Java/Python PDF library, so their body text and page references could not be reviewed here. PDF-derived detail below is therefore **not** treated as confirmed. The feedback itself transcribes the requested certificate content (lines 104–122), but sample PDF layouts remain unverified.

## Explicit conflicts and undecided scope

- “Nigeria Property Vault” is the repository/product name, while Sep. 2024 feedback requests “My Property Vault.” No later explicit brand approval is in the checked-in evidence.
- Feb. 2024 search definition says survey-plan number **or** certificate number; the verification UI/backend uses coordinates. The intended relationship between these is unclear.
- Early client feedback requests optional publication; later comments say only relevant non-identifiable information should appear in analytics and detailed owner information may be paid/limited. Visibility and paid report rules need a definitive field-level policy.
- Pay-per-use is discussed as the likely launch model, with subscriptions later, but no prices or entitlement matrix are confirmed.
- Manual KYC verification is suggested as a stopgap; later feedback says identity upload seemed automatically accepted. No final KYC release rule is documented.
- The PDF product requirements and examples are attached but could not be extracted in this environment. This matrix does not claim those PDFs were fully reconciled.
